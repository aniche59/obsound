Got Questions?

Frequently Asked Questions

How does obsound map micro-genres compared to commercial algorithms?

Mainstream platforms rely on pay-for-placement and engagement auto-play loops. ObSound maps songs based on acoustic fingerprinting, harmonic keys, synthesized timbral characteristics, and human underground curation — with zero corporate ad placement.

What is a "Crate" and how do I export it?

Inspired by vinyl digging, a Crate is your personal sandbox. You can bookmark underground tracks directly in your browser storage and export the entire collection as a clean JSON file at any time.

Can I submit new underground nodes with React client-side validation?

Yes! Use the "+ Submit Node (React)" button in the graph app or visit the React Studio. The client-side validation engine verifies all metadata (BPM, year, URL, and tags) and injects the new node into the live physics graph immediately.
